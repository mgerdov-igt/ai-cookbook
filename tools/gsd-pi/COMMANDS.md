# GSD Pi Basic Commands

Use these commands during daily work.

## Start and status

```text
gsd
/gsd status
/gsd config
```

## Quick task and automation

```text
/gsd quick "Summarize this repository and propose a plan"
/gsd auto
```

## Common control flow

```text
/gsd status
/gsd quick "Implement X in small steps and run tests"
/gsd status
```

## Good prompt pattern inside GSD

```text
Goal: Add endpoint X
Constraints: Do not change public API Y
Done when: Tests A and B pass
```

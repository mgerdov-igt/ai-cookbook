# GSD Pi Overview

## What it is

GSD Pi is a local-first coding agent that runs in your terminal.
It helps plan work, implement changes, and track progress in one flow.

## What makes it unique

- Strong planning workflow (milestones, slices, tasks)
- Good for longer, multi-step execution
- Project memory and status tracking built into the experience

## Recommended use

Use GSD when work is larger than a quick edit and you want structure.

Best for:
- Multi-step features
- Refactors with checkpoints
- Tasks where plan and execution should stay connected

# OpenCode Cost Control

OpenCode is a client; usage and billing depend on the selected provider and your organization's terms. Check the provider's current usage and rates rather than guessing from the model name.

- Use only providers approved for your work. See [setup](./SETUP.md) for a generic provider configuration example.
- Match model capability to task risk; use a stronger model when ambiguity or impact warrants it.
- Keep requests scoped, provide only relevant files and context, and stop sessions that are no longer useful.
- Review the provider's usage or billing page for actual consumption.

For general guidance, see [Common best practices](../../knowledge/COMMON-BEST-PRACTICES.md).

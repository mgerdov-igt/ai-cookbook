# OpenCode Overview

OpenCode is an open-source coding agent with terminal, desktop, and IDE interfaces. It supports multiple configured model providers.

Use OpenCode when you want to choose from multiple model providers. Use only providers and models approved for your organization. Some models, such as GLM-5.3, may be available only through a specific provider or coding tool.

OpenCode recommends WSL for the best Windows compatibility. This cookbook keeps Windows and PowerShell as the default. See [WSL2 setup](../wsl/SETUP.md) before installing OpenCode in Linux; its [networking guide](../wsl/NETWORKING.md) covers VPN and proxy issues.

# OpenCode Basic Commands

Run these from a repository directory.

## PowerShell

```powershell
opencode --version
opencode
opencode run "Explain the main modules in this repository. Do not change files."
opencode models
```

## In the TUI

- `/connect` — configure a provider credential
- `/models` — list or switch configured models

Choose only providers and models approved for your environment. For a provider config example, see [Setup](./SETUP.md).

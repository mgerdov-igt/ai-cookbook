# Spec Kit Cost Control

Spec Kit creates planning files. Your AI coding tool and model provider bill for model use.

- Start with one small feature instead of asking an AI tool to specify the whole codebase.
- Resolve only ambiguities that affect scope, design, or acceptance.
- Keep useful project facts in docs and link to them instead of repeating them in each prompt.
- Use the model and verification depth appropriate to the change's risk; check your provider's current usage and limits.

See [Common best practices](../../knowledge/COMMON-BEST-PRACTICES.md) for cross-tool guidance.

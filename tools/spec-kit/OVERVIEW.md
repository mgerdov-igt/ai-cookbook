# Spec Kit Overview

Spec Kit is a free, open-source tool for planning feature work. It provides templates and agent skills to turn a request into a spec, plan, tasks, code, and final checks.

Spec Kit is not an AI coding tool by itself. It works with a supported AI coding tool. Spec Kit creates files that help the team review the request, plan, tasks, and progress.

Use the full feature steps when the work needs clear requirements and approval. For a small, safe change, a short plan and the repo's usual checks may be enough.

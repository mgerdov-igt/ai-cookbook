# WSL Overview

Windows Subsystem for Linux (WSL) runs a Linux distribution, such as Ubuntu, on your Windows PC. WSL2 runs Linux in a managed virtual machine and is the default for new installations.

Use WSL when a tool or project needs Linux commands. Windows and WSL have separate files, programs, certificates, and environment settings.

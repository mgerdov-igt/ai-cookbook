# Codex CLI Cost Control

Codex usage and limits depend on the account or API plan in use. Check the current plan details rather than assuming a fixed rate.

- Match model capability to task risk and complexity.
- Keep requests bounded and provide only relevant context.
- Use a separate review pass when it adds value; avoid repeating broad reviews without a reason.
- Review current usage and limits in the account or billing interface.

For general guidance, see [Common best practices](../../knowledge/COMMON-BEST-PRACTICES.md).

# Quickstart

Start here first. This page helps you choose a tool and points you to setup. Use [10-minute onboarding](./10-MINUTE-ONBOARDING.md) for guided setup or [Fastest path by role](./FASTEST-PATH-BY-ROLE.md) for role-based recommendations.

Before you install anything, scan [Tool selection cheat sheet](tools/TOOL-SELECTION.md) if you are not sure which tool you actually need.

If you prefer a role-based recommendation, use [Fastest path by role](./FASTEST-PATH-BY-ROLE.md).

## 1) Pick a start point

Choose one:
- I know the task but not the tool: [Tool selection cheat sheet](tools/TOOL-SELECTION.md)
- I want a role-based recommendation: [Fastest path by role](./FASTEST-PATH-BY-ROLE.md)
- I want to get running immediately: [10-minute onboarding](./10-MINUTE-ONBOARDING.md)

## 2) If you already know the tool

Go straight to setup:
- [Copilot CLI setup](tools/copilot-cli/SETUP.md)
- [Claude Code setup](tools/claude-code/SETUP.md)
- [GSD Pi setup](tools/gsd-pi/SETUP.md) for large, staged work
- [OpenCode setup](tools/opencode/SETUP.md)
- [Codex CLI setup](tools/codex/SETUP.md) for implementation plus a separate review

## 3) If you are setting up a machine

Follow [Prerequisite tools](tools/PREREQUISITES-TOOLS.md).

Then apply [PowerShell environment setup](tools/powershell/SETUP.md).

Using Linux tools on Windows? Follow [WSL2 setup](tools/wsl/SETUP.md), then install tools inside your Linux distribution.

## 4) After first success

Read [Common best practices](knowledge/COMMON-BEST-PRACTICES.md).

For a shared way to plan and check work in a repo, see [Repo workflow](knowledge/REPO-WORKFLOW.md).

For a feature that needs clear requirements linked to tasks and tests, use the [Spec-driven feature workflow](knowledge/SPEC-DRIVEN-WORKFLOW.md).

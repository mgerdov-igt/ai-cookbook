# Experiments

Use an experiment to answer a question about how you work with AI. Keep notes in your own project or private files. Separate numbered files are optional.

Record what you need to compare results:

1. Question and possible answer to test
2. Task, project information, and methods compared
3. Actual results, such as corrections, errors, your time, and tool use
4. Differences that affect comparison, such as task size, tool, or test order
5. Method to keep, change, or stop

Write `unknown` for missing measurements. Message counts are not token counts. Fewer messages do not prove better quality. Most lessons only need a short note. Use a full record when the comparison needs it.

## First experiment

Start with the [current-work worksheet](./baseline.md). Describe one real task and how you completed it. Do this before changing tools or adding steps.

No submissions are required. Do not put private information in this course project or an AI tool without permission. Remove private details before sharing examples.

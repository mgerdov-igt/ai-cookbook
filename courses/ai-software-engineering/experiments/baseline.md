## Current Process

Describe what happened, not what you planned to do.

1. How did you receive the request? How did you make it clear?
2. What did you tell the AI? Which project files and rules did you give it?
3. Did it read files or search before suggesting changes?
4. Was there a work plan or system design? Who approved it?
5. How was work divided (or kept together)?
6. What did the AI change? How did you review those changes?
7. Which tests, builds, code checks, or manual checks ran? Who ran them?
8. Which corrections or repeated work were needed?
9. How did you decide the change was ready to commit, merge, or release?
10. What did you save for later tasks? What was lost when the chat ended?

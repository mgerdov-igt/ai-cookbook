# Agent Task

## Use What You Need

For a small change, state the goal, rules, checks, stop rules, and your approval. One line can combine G1-G3 approval. It must name the approved result and design rules. A separate specification or approval table is optional. Never omit required behavior or checks.

For a feature with several tasks or high risk, fill in the approval details below. Link existing information instead of copying it. Remove unused sections. A draft task is not permission to write code.

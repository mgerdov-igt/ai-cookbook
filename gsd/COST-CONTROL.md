# GSD Pi Cost and Token Control

## Use model strength where it matters most

- Use a strong reasoning model for milestone planning and risk gates.
- Use a code-focused or balanced model for slice execution.

## Keep auto mode bounded

- Run one slice at a time.
- Require verification commands per slice.
- Stop at defined checkpoints.

## Reduce unnecessary context

- Pass only the files needed for the current slice.
- Ask for short summaries between slices.
- Start a fresh session after major milestones.

## Prefer structure over repetition

- Create milestone, slices, and tasks once.
- Reuse the plan instead of re-explaining the whole project every turn.

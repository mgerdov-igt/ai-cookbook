# GitHub Copilot CLI Overview

## What it is

GitHub Copilot CLI is an AI coding assistant that runs in your terminal.
It is tightly connected to your GitHub account and Copilot entitlement.

## What makes it unique

- Native GitHub integration
- Good interactive chat flow in terminal
- Strong fit for code tasks plus GitHub-aware workflows

## Recommended use

Use Copilot CLI for fast day-to-day coding support.

Best for:
- Quick code changes
- Explaining code and commands
- Iterative implementation with frequent reviews
